**關鍵結論**
1. **H1 重新分類**：不是素材批次 ⇒ 4 種地圖形態 = `layout.pattern` 欄位（`rooms`/`corridor`/`arena`/`ring`），**屬工程工單**（`level_generator.gd` 小改）。素材線因此**正式收線**。
2. **摳底是這條產線唯一真難點**：AI 給洋紅漸層底 + 黑陰影 + 誤畫色塊 ⇒ 三種方案（Pillow floodfill / 洋紅色相 / 邊緣中位色距離）**全部推翻**；定案 = **相鄰差泛洪（`_flood_from_border`，th=30）+ 純底色補挖（距邊緣中位色 <50）**，見 `g1_postprocess.py::key_bg`。
3. **4 方向獨立出圖會風格漂移** ⇒ 必須**數量化驗收**，不能憑目視。
4. **精細度體檢結論：不做大規模精修**。舊素材（細線條寫實）vs 新素材（Q 版大輪廓）風格差異**判斷為不修**——實機 `DNF_GAME_SCALE=0.25`，192px 只顯示 48px，舊怪的 1–2px 細節會被 4× 降採樣吃掉；重做需 40 張 AI 圖換一個「實機看不到」的改動。只修了 1 個真瑕疵：`rat_swarm` 正面是單隻大鼠、側背卻是鼠群（1 張 AI 圖重出正面）。
5. **順手修掉產線 bug**：`gen_monster_actions.py` 的 `--only` 從一開始就失效（`ids = args.only if …` 下一行又無條件覆蓋）。

**匯入變通（重要）**：Godot 編輯器寫快取是「先寫 `.tmp` 再 rename」，該 rename 在**本工作區必然失敗**（`WinError 5`，檔案被外部行程鎖住，最可能是 WorkBuddy 桌面版的檔案監控）⇒ 解法 = 複製到工作區外跑 `--headless --editor --quit`，再把新增的 `.import`/`.ctex` 搬回。
⚠️ 搬回中斷會留下 **0 byte 的 `.import`** ⇒ `UISkin.texture()` 回 null ⇒ 圖標**靜默消失**（本次中了 `elem_poison_24.png.import`）。**搬完務必掃 `<50 bytes` 的 `.import`**。
