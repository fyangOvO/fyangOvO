## 1. 現狀盤點（藍圖的事實基礎，均已核實）

### 1.1 已具備（v2.0 全量）

- **三職業**：戰士 / 弓手 / 法師
- **技能**：36 個（`skills.json`）、7 形態（單體 / 自 AoE / 閃避 / 投射物 / 地面 DoT 場 / 召喚 / 自 buff）
- **符文**：24 個（`runes.json`）、每技 3 socket、可改形態 / 元素 / 增幅、5 級二選一分支
- **局內三選一**：局內 1→10 級，每級抽 3 選 1；池 = `RunePool`（**屬性加成類**，~15 個選項）
- **20 關**：`level.tscn` 共用一份，4 關手繪 + 16 關程序化；BOSS + 6 種目標；深淵 / 高塔特殊玩法
- **局外 meta**：賬號 1–30 級 + 天賦 3 分支 + 聲望 + 成就
- **裝備**：稀有度 10 檔、詞綴 48、套裝 3（2/4/6 檔）、傳奇 PROC、寶石鑲嵌 / 彩裝成長
- **鍛造**：強化 / 洗練 / 分解 / 合成 / 神話重鑄
- **打擊感 ①–⑧**：磁吸 / DoT 跳字 / 屏震頓幀分級 / 地面殘留 / 稀有慶祝 / 拾取反饋 / 掉落 pop
- **驗證**：`self_check` 122 項 + 77 個 `verify_*` + 7 策劃校驗器（全綠 ~230s）

### 1.2 與《Playground 開發描述 v2》（爆款暗黑向）的差距

| # | 願景（v2 目標） | 現狀 | 差距 |
|---|---|---|---|
| 1 | 50–200+ 同屏潮水割草 | 20 關投放是 **demo POC 值，非 D5 終值** | 密度不足，割草爽感沒到 |
| 2 | Hades 式 boon 池 ~40：**新技能 / 升級技能 / 遺物 / 屬性**四類 | 三選一池**全是屬性類**（~15） | 缺技能升級 / 遺物 / 元素附着 → 無 build 聚變 |
| 3 | 第 10 分鐘滿屏 chaos（3 場 + 投射物 + 召喚同屏） | 依賴技能鋪場 + 密度 | 需密度 + 三選一聯動才能成 |
| 4 | 符文 = **把技能改造成不同流派** | 符文主要加數值，7 個 modifier 未接 | 改造能力弱 |

### 1.3 未結遺留（可進藍圖的候選）

- 7 個 modifier 未接（`combo_hits` / `combo_damage_pct` / `linger` / `afterimage` / `pulse` / `summon_damage_pct` / `buff_potency_pct`）
- `04-check` 上限 20 vs 30 口徑；`boss_ember_lord` 等級帶 19→13 偏離；`reward_xp` 是否抬（≈×2.8）
- 深淵表 `rune_drop_chance`（0.05/0.30）未消費
- 地面殘留貼圖未做視覺抓圖（鐵律 7：缺像素證據）
- `BIG_NODE_MECHANICS` 前 5 機制仍為展示字串
