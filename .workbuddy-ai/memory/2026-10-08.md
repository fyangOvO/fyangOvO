### 落地
- 新增 `game/scenes/main/intro.tscn`（`CanvasLayer` + 腳本，與 `main_menu.tscn` 同款：
  `.tscn` 只掛腳本、全部子控件在 `_ready()` 程序化建）。
- 新增 `game/scripts/ui/intro_screen.gd`（`class_name IntroScreen`）。
  播放序列：① 黑幕淡入（火山生態 backdrop）→ ② 標題徽記「七傳說」+ 副標題「勇者斗恶魔」→
  ③ 三勇者**保持隊形**自畫面左側整體滑入（戰士/弓箭手/法師）→ ④ 魔王
  （`boss_ember_lord`）在岩漿紅光中顯形 + 火星 → ⑤ 第二行字幕「三职业勇者 · 共伐魔王」→
  ⑥「按任意键开始」閃爍。第一次輸入 = 跳過（落終態），第二次輸入 = 進主菜單；
  序列播完 6s 自動前進。
- 接線：`SceneManager` 新增 `SCENE_INTRO` + `change_to_intro()` / `change_to_main_menu()`；
  `main.gd` 正常啟動路徑改為「先進片頭」。`--verify` / `--smoke` 兩條分支提前 return，
  **不受影響**（`verify_e2e` 自己直接 `change_scene(SCENE_MAIN_MENU)`）。

### 素材（**全部既有，零新增美術檔**）
- 背景 `UISkin.texture("backdrop_volcanic")`（火山 + 岩漿 640×360）
- 標題 `UISkin.texture("title_emblem")`（336×112）
- 三勇者 / 魔王走 `EnemyBase.resolve_character_set(id)`（唯一精靈解析鏈：用戶覆蓋 →
  素材包多幀集 → 內建單張），故玩家可用 `user://content/characters/<id>/` 替換。
- 一律 **0.5× 整數縮放**（畫布 192 / 256 ⇒ 畫面 96 / 128）；腳底對齊
  （`_center_from_feet()`）；掛**子節點橢圓陰影**（自動跟隨位移 + 繼承 modulate）。

### 本輪踩到並修正的坑
1. **錯開入場會穿模**：三人同起點 + 錯開 0.28s ⇒ 後入場的法師直接蓋在先入場的弓箭手身上
   （截圖 03 目視發現）。修法：改為「同位移量的整體隊形滑入」（`HERO_ENTER_SHIFT = 340`），
   間距恆定、中途不互相遮擋，且更貼「並肩出發」的主題。
2. **角色飄著沒落地**：加橢圓陰影（`_make_shadow_texture()`）。子節點會**繼承父級 scale**
   ⇒ 子 scale 要除以父 scale 還原目標像素尺寸；並用 `z_as_relative = false` 把陰影釘在
   絕對圖層（否則子節點會畫在角色腳上）。
3. **自洽式偽校驗風險**：驗證腳本原本硬編碼 `0.85` 去比對 `GLOW_ALPHA`，改數值後立刻假紅。
   已改為 `(script).get_script_constant_map()` **從被測腳本自己的常量讀**（站位 `HERO_FEET_XS`
   同樣處理）。
