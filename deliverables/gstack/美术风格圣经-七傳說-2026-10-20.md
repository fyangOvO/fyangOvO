# 「七傳說」美術風格聖經 + 素材管線方案

> **產出**：2026-10-20 · 依 `create-game-assets` 流程（先檢查再發明 → 鎖技術幀 → 定義視覺系統 → 素材清單 → 管線）。
> **狀態**：方向草案，色值/尺寸以 `GameConstants` / 現有代碼為錨點，落地前逐項對齊。

---

## 1. Game frame（技術幀）

| 項 | 值 |
|---|---|
| 引擎 / 渲染 | Godot 4.7.2 · 2D 俯視 · `canvas_items` + **integer** 縮放 |
| 原生視口 / 常見縮放 | **640×360**（×2/×3 整數倍）|
| 網格 | tile **32×32**；角色 **48×48**（Sprite 層 + 陰影層）|
| 過濾 | **Nearest**（紋理過濾鐵律）｜ 禁止運行時旋轉精靈（方向動畫預烘）|
| 視角 / 朝向 | 正俯視 45° 斜角；四方向（下/上/左/右）預烘 |
| 玩法基調 | 2D 俯視暗黑刷寶 ARPG（割草 × build 聚變）|

## 2. 現狀盤點（inspect before inventing）

- 三職業：戰士（金 `D9A441`）/ 弓手（綠 `8FBF5F`）/ 法師（藍 `7FA8E8`）
- 稀有度 10 檔（白→彩，光柱/形狀 10 檔對齊）、元素 6 系（物理/火/冰/雷/毒/影）
- 三 biome：幽林 `forest` / 灰燼堡 `volcanic` / 霜淵 `frost`（程序化像素占位配色）
- 打擊感 ①–⑧：傷害飄字、震屏、頓幀、粒子、地面殘留貼花（自繪）
- 素材現狀：**地圖程序化像素占位、圖標無（格子文字）、BGM 無**（CONTENT_GUIDE §「當前內置狀態」）

## 3. Visual system（視覺系統定義）

### 3.1 Shape language（形狀語言）
- **粗像素塊 + 統一 1px 暗描邊**（深墨 `#101418`），保證 640×360 下剪影清晰
- 角色 = 頭身比 1:1.2 的像素塊；怪物 = 更大剪影（Boss 更大一號）
- 所有關鍵單位以「剪影可讀」為第一優先（小屏幕鐵律）

### 3.2 Palette roles（調色板角色）
- **角色主色**：三職業金/綠/藍（上表）——職業可讀性，永不偏移
- **稀有度色**：10 檔漸進（白→彩）——裝備/掉落可讀，錨 `GameConstants.Rarity`
- **元素色**：火紅/冰青/雷黃/毒綠/影紫 + 物理白——技能/異常 HUD 可讀
- **環境**：幽林（深綠棕）/ 灰燼堡（橙黑）/ 霜淵（藍白）——biome 基底，與角色形成明度對比（環境偏暗、單位偏亮）

### 3.3 Materials / Edge / Lighting
- 材質：純像素，**無抗鋸齒、無漸變**；金屬/魔法以「亮部-暗部兩色塊」表達
- 邊緣：**1px 深色描邊**（不含地面 tile；地面用圖集自帶接縫）
- 光照：**頂光**，高光偏上、陰影偏下；對比度中高（暗背景亮單位）

### 3.4 Detail density（細節密度）
- 640×360 下：角色聚焦在**剪影 + 職業色 + 狀態光暈**，不堆小細節
- 地面 tile：低細節、重複可容忍（程序化生成，單 tile 32×32 內保持 3–5 個色塊）
- 特效：高對比閃光（飄字/稀有慶祝），壽命短、強衝擊

### 3.5 Motion character（運動特徵）
- 方向動畫預烘（4 向），無運行時旋轉；幀數：移動 4–6 幀、攻擊 3–4 幀、受擊 1 幀
- 異常狀態（灼燒/冰凍等）以**頂部圖標 + 顏色疊層**表達，不改骨骼

### 3.6 Explicit exclusions（明確排除）
- 不寫入畫面文字/浮水印/簽名（生圖 EXCLUDE 塊）
- 不引入 3D/真實光影/抗鋸齒漸變
- 不混入第二套視覺風格（每個素材只服務一個 biome/職業）

## 4. Technical contract（技術契約）

| 項 | 值 |
|---|---|
| 尺寸 | tile 32×32；角色 48×48（含 1px 描邊內收）；圖標 32 或 48 |
| Alpha | 單位/特效/圖標**必須透明底**（生圖後用腳本校驗 alpha）|
| 錨點 / 基準線 | 角色 pivot 腳底中心；地面 tile (0,0) 左上 |
| 過濾 / 壓縮 | Nearest；無 mipmap；RGB/RGBA 8bit |
| 色空間 | sRGB |
| 命名 / 目錄 | 依 `CONTENT_GUIDE.md`：`tilesets/<biome>/atlas.png+json`、`characters/<怪物id>.png`、`fx/<特效id>.png`、`icons/<icon_path 同名>.png`、`music/<bgm_path 同名>.ogg` |

## 5. Asset manifest（素材清單草稿）

| 類別 | 項目 | 尺寸/幀 | 來源 | 現狀 |
|---|---|---|---|---|
| tileset | forest / volcanic / frost 各 1 atlas | 32×32 圖集 | 生成→接縫修→3×3 驗證 | 占位 |
| character | 三職業各 4 向 × 移動/攻擊/受擊 | 48×48 | 生圖→像素化→4 向 | 缺 |
| monster | 24 怪物（spider_cave 等） | 48×48 | 同上 | 缺 |
| fx | 技能/飄字/粒子 33 條 | 單幀/序列 | 現有 + 補充 | 部分 |
| icon | 裝備圖標（暫格子文字） | 32/48 | 生圖→透明底 | 缺 |
| music | 3 biome BGM | .ogg | 授權素材 | 無 |

## 6. 素材管線方案（production path）

依 `create-game-assets` 分層，真像素畫走「生圖 → 像素工具校正」而非直用生圖：

```
① 批准種子：選 1 張代表角色/風格板 → 原生尺寸 + 對戰背景目視審
② 生成家族：每批小批量、保持調色板/視角/比例/光照/描邊不變（生圖當草稿）
③ 像素校正：grid/調色板/簇/幀 → 用像素工具（Aseprite 類）真像素化（草稿非成品）
④ 規範化：裁切/錨點/命名/壓縮/alpha 校驗 → `asset_report.py` 出具 QA 報告
⑤ 預覽：`build_preview_sheet.py` 生成最近鄰接觸表（棋盤底）目視
⑥ 導入：Nearest/sRGB/無 mipmap → 依 `godot-asset-generator` import 配置
⑦ 上下文驗證：原生 640×360 + 遊戲內目視（剪影/比例/接縫/alpha/碰撞）
⑧ 記錄來源：授權/生成注記/編輯史 → `asset-manifest.json`
```

**質量門**：生圖結果**不算**生產就緒；須過技術檢查 + 引擎內/原生尺寸目視（create-game-assets §Quality gates）。
