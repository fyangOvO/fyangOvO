# 2026-10-22 工作誌（append-only）

## 主題：防具分件錨點「位置沒對上」修復輪（裝備可視化第1期·防具外觀層延伸收尾）

### 背景
用戶回饋「位置沒對上繼續優化吧」：archer/mage 穿全套防具時分件與身體錯位（法師旁出現「獨立金屬人形」）。上一輪已把根因鎖定為「身體素材黑底烘入 + 主體畫偏」，本輪落地修復。

### 根因（最終確認，鐵證）
1. **身體素材**（`pack/creatures/<cid>/char_<cid>_idle_<dir>_0N.png`）：**不透明黑底烘入**（81% 像素 alpha=255、底色 (11,13,18)），且**主體畫偏**——面朝右（e/ne/s/se）主體質心偏右 +17~+25px（畫布），面朝左（w/nw/sw）偏左 −17~−26px（畫布）；分件素材（`pack/armor/`）正常透明且主體居中（質心≈96）。
2. 身體主體偏移量（192 畫布，濾黑底實測）：warrior e+21.3/n+19.1/w−22.3/s+21.8；archer e+17.3/w−18.3；mage e+24.2/w−25.2 等（完整表見 dir_measure.txt）。
3. 錯位幅度 = 主體偏移量（±17~26 畫布 px），與「獨立人形」觀感：裝備展示 zoom 放大後肉眼明顯。

### 修復（改動見 git log）
- `player_controller.gd` 新增 `ARMOR_ANCHOR_X_OFFSET`（**職業×朝向錨點偏移表**，畫布 px）+ `_armor_anchor_offset()`（`_anim_dir` 空時回退 `_facing` 即時方向）。
- `_mount_armor_piece` / `_refresh_armor_sprite`：錨點 x 偏移走 **`offset.x`**（畫布座標，渲染自動乘 scale）。

### 踩坑（必須記入 IRON-RULES）
- **`Sprite2D.position` 是世界座標，不乘自身 scale**：把畫布偏移（24px）塞進 `position.x` 會放大 4 倍（scale 0.25），分件右移 96 畫布 px 反而錯位更嚴重。**畫布偏移必須走 `offset.x`**（乘 scale）。第一次修復用 position 失敗，量測後發現單位錯誤，改用 offset 立即貼合。

### 驗證
- **分離渲染**（capture_split，z001 1:1）：三職業 RIGHT/LEFT 分件與身體主體質心誤差 <1px（warrior 0.5 / mage 0.8 / archer 0.0；LEFT 全 <0.5px）。
- **玩家視角全套圖**（capture_armor_piece）：mage/archer 全套穿甲後為**單角色**（不再出現獨立金屬人形），目視驗收通過。
- **全量回歸**：`python tools/run_regression.py` → **失敗 0 項、exit 0（162.3s）**。
